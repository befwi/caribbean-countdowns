# Governance

## Project structure

Caribbean Countdowns is maintained by the [countdowns-co](https://github.com/countdowns-co) organisation on GitHub. The primary maintainer is [@mangroroot](https://github.com/mangroroot).

## Roles

### Maintainer

The maintainer is responsible for:

- Reviewing and merging pull requests
- Managing GitHub releases and version tags
- Triaging issues and bug reports
- Maintaining branch protection rules and CI configuration
- Responding to security disclosures (see [SECURITY.md](SECURITY.md))

### Contributors

Anyone who submits an accepted pull request is a contributor. There is no formal committer role beyond the maintainer at this time.

## Decision making

Decisions about features, architecture, and direction are made by the maintainer. For significant changes, an issue is opened first to discuss the approach before any code is written. Contributors are encouraged to propose ideas via issues.

Pull requests are reviewed against the standards in [CONTRIBUTING.md](CONTRIBUTING.md). All PRs must pass the `build` CI check. The CODEOWNERS file enforces maintainer review before merge.

## Changes to governance

Any change to this document is made via pull request, the same as any other change to the project.

## Continuity

The project repository and all assets are held under the countdowns-co GitHub organisation. In the event the primary maintainer is unavailable for an extended period, access to the organisation can be transferred to a trusted contributor. Any contributor who has had at least one PR merged may request maintainer access by opening an issue.

## Code of conduct

All participants are expected to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
